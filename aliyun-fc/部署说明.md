# 阿里云函数计算 FC 每日自动同步（可选，让更新不依赖你的电脑）

这个目录是给**阿里云函数计算 FC** 用的：把「抓取 6 个官方来源 → 构建单文件页面 → 发布到 PocketBay」
这一整条链路搬到阿里云上，每天定时跑一次。跑在阿里云的好处是**出口 IP 在国内**，
能直连省教育厅、辽工大、大连大学（`cxcy.dlu.edu.cn`）和省双创平台（`cxcy.upln.cn`）——
后两个是 GitHub Actions 的境外机器连不上、公共 CORS 代理又经常超时的站点。

## 一、目录内容

| 文件 | 作用 |
| --- | --- |
| `aliyun-fc-site-sync.zip` | **上传到阿里云的就是这个包**（26 KB，纯标准库，无第三方依赖） |
| `index.py` | 函数入口 `index.handler`：seed 缓存 → 抓取 → 构建 → 上传 PocketBay → 轮询状态 |
| `build_pkg.py` | 改完仓库代码后重新打包：`python build_pkg.py` |
| `s.yaml` | Serverless Devs 命令行部署描述（可选，控制台点选也行） |
| `部署说明.md` | 就是本文件 |

## 二、控制台部署（约 3 分钟）

1. 打开 [函数计算 FC 控制台](https://fcnext.console.aliyun.com/) → 左上角选一个**国内地域**（如华东1 杭州）。
2. 「函数」→ **创建函数** → 选择 **使用示例创建**（或「事件函数」）→ 运行时选 **Python 3.10**。
3. 函数名称填 `ln-cxcy-sync`；**代码上传方式**选「通过 ZIP 包上传」，选择
   `aliyun-fc-site-sync.zip`；**请求处理程序**填 `index.handler`。
4. 展开「高级配置」：
   - 内存 **256 MB**，超时时间 **300 秒**（抓取含大连大学 32 条详情页并发，实测约 2–60 秒）；
   - 环境变量加两条：
     - `POCKETBAY_TOKEN` = 你的 PocketBay API token（即 `C:\Users\ASUS\.pocketbay\token.txt` 里的那串）
     - `POCKETBAY_PROJECT` = `3681`
5. 创建完成后点「**测试函数**」，事件内容填 `{}`，执行成功会看到日志最后一行
   `POCKETBAY_DEPLOY_OK running/success`，返回 JSON 里有 `"counts": {"total": 106, ...}`。
6. 左侧「**触发器**」→ 创建触发器 → 类型 **定时触发器**：
   - 触发周期：`0 0 8 * * *`（秒 分 时 日 月 周 → 每天 08:00:00）
   - 时区：**Asia/Shanghai**
   - 想更勤就改成 `0 0 * * * *`（每小时整点），成本依然极低。

## 三、命令行部署（可选）

```bash
npm i -g @serverless-devs/s
s config add            # 填阿里云 AccessKey
export POCKETBAY_TOKEN=你的token
s deploy                # 读 s.yaml，创建/更新函数 + 定时触发器
s invoke                # 立刻跑一次
```

## 四、跑起来之后的分工

| 执行者 | 时间 | 覆盖来源 | 发布目标 |
| --- | --- | --- | --- |
| **阿里云 FC（本方案）** | 每天 08:00（可改每小时） | **全部 6 个**（含省双创平台、大连大学） | PocketBay |
| 你的电脑（计划任务 + 开机补跑） | 每天 08:00，错过后开机补 | 全部 6 个 | GitHub + PocketBay（内容相同会跳过） |
| GitHub Actions | 每天 08:00 | 4 个（省双创平台、大连大学为「沿用缓存」） | GitHub Pages + PocketBay |

三者互不冲突：内容哈希相同就不重复部署；FC 挂了还有本机和 Actions 兜底，本机关机 FC 照样更新。

## 五、函数逻辑速览（`index.py`）

1. `seed_cache()`：先抓一次线上页面，把里面内嵌的上一份快照写到 `/tmp/site/data/notices.json`，
   这样某个来源临时抽风时能用上次数据兜底（FC 冷启动 `/tmp` 是空的，没这步就会少条）。
2. `run_scrape()`：调仓库里的 `scraper/scrape.py`（用 `SITE_ROOT` / `DATA_FILE` 环境变量把输出指到 `/tmp`）。
3. `run_build()`：调 `tools/build_page.py` 生成单文件 `index.html`（CSS/JS/数据全内联）。
4. `deploy()`：multipart 上传 zip 到 `POST /api/projects/3681/deploy`，再轮询 `/deploy/status`
   直到 `phase=success`，失败抛异常 → 函数标记失败（可在控制台配告警）。

## 六、常见问题

- **改了页面代码怎么办**：在仓库里改完 `assets/`、`tools/`、`scraper/`，运行
  `python D:\大肥鱼\aliyun-fc\build_pkg.py` 重新打包，再上传新 zip。
- **token 失效**：函数日志会报 401/403，去 PocketBay 重新生成 token 更新环境变量即可。
- **超时**：把超时提到 600 秒、内存提到 512 MB 通常足够；抓取本身是并发读详情页。
- **地域选择**：选国内地域（杭州/北京/上海/深圳均可），**不要选海外**，否则又回到连不上国内站的老问题。
- **费用**：每天一次、单次几秒到一分钟、256 MB，属于按量计费的极低用量；新账号一般有试用额度，
  具体以控制台账单为准（不做金额承诺）。
- **测试与手动触发**：控制台「测试函数」或 `s invoke`，两者都等价于一次定时触发。
